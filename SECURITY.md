# Security policy

## Supported versions

Security fixes go into the latest release of `pydeako-community` on PyPI.

## Reporting a vulnerability

Please report it privately through [GitHub's private vulnerability reporting](https://github.com/pydeako-community/pydeako/security/advisories/new), not in a public issue. Say which version you use and how to reproduce the problem.

The library talks to devices on the local network over a plain-text protocol without authentication, which Deako defined. Reports about the protocol itself are best sent to Deako.
